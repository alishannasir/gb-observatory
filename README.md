# GB Observatory

Buildless research portfolio. Serve `dist/` over HTTP (not file://):

```sh
python3 -m http.server 8765 --directory dist
```

The browser loads JSON evidence from dist/assets. No dependency installation or build step is required.

## Evidence

Population ledgers preserve conflicting source versions. Literacy is 2017 age10+; MICS service estimates refer to2024–25 with explicit denominators. Historical boundary equivalence and2025 observed population remain unresolved. Climate and migration entries describe mechanisms and case studies, not regional causal rates.

## Checks

JavaScript syntax checked. Browser-tested source selection, estimate toggle, district comparisons, services selector, migration tabs and source search. Mobile viewport checked for horizontal page overflow. No runtime console errors observed during these checks.

External source availability may change; several links deliberately open official catalogues and are labeled accordingly. Fonts load from Google Fonts with system fallbacks.
